Cadence 0.2.1 adds an **AI DJ**, **Jellyfin**, an **Android app**, two new **admin pages**, and a round of **security hardening**. It also adds a Nightly download channel.

## New

- **AI DJ.** A nonstop, personalised mix with spoken intros. The model is your choice: run it **on the server** (works on every device with no setup; the server owner adds Ollama, LM Studio, llama.cpp, any OpenAI-compatible service or Anthropic from the admin panel, and API keys stay encrypted on the server), **on your own computer**, or **share your computer's model with your phone** through the server. On an iPhone or iPad with Apple Intelligence (iOS 26+) the DJ can use Apple's on-device model, and, experimentally, Gemini Nano on supported Android phones. Details: [docs/AI_DJ.md](https://github.com/Hornet-Linux/cadence-music/blob/main/docs/AI_DJ.md).
- **Jellyfin.** Browse, search and play your Jellyfin music in Cadence, with cover art, favourites, playlists and play counts reported back to Jellyfin. It works through the Cadence server, so phones need no direct access to Jellyfin. The server owner sets the address once (`JELLYFIN_URL`, or the new admin page); everyone signs in with their own Jellyfin account. The AI DJ can pick from your Jellyfin library, so it works without Spotify. Details: [docs/JELLYFIN.md](https://github.com/Hornet-Linux/cadence-music/blob/main/docs/JELLYFIN.md).
- **Android app.** A native shell around the web player with background playback, notification and lock-screen controls. Install `Cadence.apk` below. It is signed with the project's release key, so later versions install over it. Details: [docs/ANDROID.md](https://github.com/Hornet-Linux/cadence-music/blob/main/docs/ANDROID.md).
- **Admin panel** (`/admin`) gains **Jellyfin** (set and test the address) and **AI providers** (add, test, edit, make default, turn off, remove) pages.
- **Nightly builds.** Every change on `main` refreshes the [Nightly](https://github.com/Hornet-Linux/cadence-music/releases/tag/nightly) pre-release with the newest installer, APK and IPA, no sign-in needed.
- Settings → About now shows the real version.

## Security

Fixes for: login rate limits that could be bypassed with a forged `X-Forwarded-For` and a limiter that wiped itself when full; unlimited guessing of sign-up invite codes; usernames being discoverable by response time; expired sessions never being cleaned up; the web player having no Content-Security-Policy; signing out of the web player leaving Spotify, Apple Music and AI keys behind for the next person; and known vulnerabilities in the server's dependencies (Fastify 5, a newer music-metadata). The AI DJ relay and the iOS and Android bridges were also hardened.

## Before you upgrade

- **`TRUST_PROXY` now defaults to "believe `X-Forwarded-For` only from a proxy on this machine or a private network".** The bundled Caddy, Caddy or nginx on the host and other containers on your Docker network keep working. If your proxy reaches the server from a **public** address, list it (`TRUST_PROXY=203.0.113.10`); if nothing sits in front of the server, set `TRUST_PROXY=false`. See [docs/SELF_HOSTING.md](https://github.com/Hornet-Linux/cadence-music/blob/main/docs/SELF_HOSTING.md#client-addresses-and-rate-limits).
- **Reconnect Spotify once** to use the AI DJ: it needs two new read permissions (top artists and recently played).
- Update the server the usual way (run the installer again). The database upgrades itself.
- The iPhone app is still sideloaded with a free Apple ID (`docs/IOS.md`). Apple Intelligence needs iOS 26 or newer on supported hardware.

## Known limits

- Spotify playback inside the Android and iOS apps (an embedded web view) is untested and may not work; the desktop apps and browsers are the reliable place for Spotify audio.
- A paused Jellyfin track whose stream link has expired will fail when you seek.
- The Windows installer is only DRM-signed for Spotify and Apple Music if the repository has the castlabs EVS secrets; macOS builds are not notarized (right-click → Open the first time).
