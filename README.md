# unnamed_music_app

A desktop music player that you own end to end. Run it entirely on your own computer, or self-host the server part on a VPS with Docker and point the desktop app at it.

## Goals

- **Desktop app**: a Windows installer (`.exe`) that works on its own, locally.
- **Self-hostable server**: optional backend shipped as Docker containers, so your library, playlists and history live on hardware you control.
- **Bring your music in**: connect or import from Spotify and Apple Music.
- **Plugins**: extend the app with plugins.
